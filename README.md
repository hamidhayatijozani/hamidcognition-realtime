# HamidCognition Realtime

> Historical real-time market and cognitive-state implementation lineage.

The canonical integrated project is **HamidCognition-Unified**. This repository remains preserved for provenance and reproducibility of the earlier real-time implementation.

Its code combines market data, P/S/T state handling, prediction, and dashboard components. Historical simulation or prediction output must not be represented as live-market validation without separate evidence.

The source components have been integrated into `HamidCognition-Unified/integrated/realtime/` where practical.
